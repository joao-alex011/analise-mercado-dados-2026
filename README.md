# analise-mercado-dados-2026
Análise do Mercado de TI (Analista e Cientista de Dados) Repositório criado para documentar a atividade prática do Projeto Integrador.

Objetivo: Investigar e tabular as competências técnicas e comportamentais mais exigidas em 12 vagas reais de dados no Brasil.

Tecnologias/Ferramentas: Excel e python para tabulação e geração de gráficos de frequência.
Principais Resultados: consegui desenvolver a habilidade de pegar dados brutos e refina-los para obter uma visão clara e organizada dos mesmos.
